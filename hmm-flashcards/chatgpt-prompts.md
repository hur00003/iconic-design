# HMM Deck: ChatGPT Image Prompts

Use these inside a ChatGPT **Project** called "HMM Flashcards". Send **one card per message**. Save each image as `NNN-pinyin.png`, for example `001-ren.png`.

---

## 1. Project instructions (paste once into the Project settings)

```
You generate illustrations for my 500-card Chinese flashcard deck, which uses my Hanzi Movie Method (HMM). Every image must follow these rules:

STYLE
- Vertical portrait image (2:3).
- Soft watercolor washes, clean ink line art, high contrast, soft paper texture.
- Match the style of any reference image uploaded to this Project.

CHARACTER TRACING (most important)
- The actor's body posture and props must physically trace the strokes of the Chinese character I give you, in the correct positions and directions.
- The stroke-forming shapes (limbs, props) are the darkest, sharpest elements in the image, set against a pale background.
- Keep the centre of the image uncluttered so the character shape reads at a glance.

SCENE
- The actor performs in the named location. The tone zone sets the mood and direction:
  Tone 1 = high, level, flat (rooftops, bridges, horizon lines)
  Tone 2 = rising (uphill, stairs, upward motion)
  Tone 3 = dipping (valleys, dips, low-then-up motion)
  Tone 4 = falling (downhill, dropping, downward motion)
  Neutral = calm, small, understated

NEVER
- Never draw any text, letters, numbers, or Chinese characters. I overlay the real character myself.

When I send a card, generate the image right away without asking questions. If you can't depict a named real person, draw a clearly inspired original character with the same signature look instead.
```
